# Patched bindings

The bindings are generated by [runic](https://github.com/Samudevv/runic) from the C headers.
Regenerating overwrites hand fixes, so each is applied by a rule in `scripts/postprocess.sh` and
also pinned by a typed variable in the package's `patched.odin`: a regeneration that drops a rule
fails to compile there instead of misbehaving at run time.

To regenerate, run `make generate`. The rules are deterministic; the output is committed.

| Rule | Where | Pin |
|---|---|---|
| `gchar *` is `cstring`, not `^char`: `image_get_metadata_key_value` (argument and result), `creator_new`, `creator_add_metadata_key_value` | `glycin` | `patched_image_get_metadata_key_value`, `patched_creator_new`, `patched_creator_add_metadata_key_value` |
| `GBytes *` and `GlyFrameDetails *` parameters are `^T`; runic 0.8 would emit `[^]T` for `loader_new_for_bytes` and `frame_details_get_pixel_density`; `to.detect.parameters: declared` in both `rune.yml` files types them `^T`, with no `arrays:` entry | `glycin` | `patched_loader_new_for_bytes`, `patched_frame_details_get_pixel_density` |
| `TYPE_FOO :: \`(gly_foo_get_type())\`` becomes `TYPE_FOO :: foo_get_type`; `LOADER_ERROR` names `loader_error_quark` | `glycin` | `patched_type_loader`, `patched_loader_error` |
| `typedef struct _GlyFoo GlyFoo` is one type: the `Foo :: _GlyFoo` alias is dropped and `_GlyFoo` renamed `Foo` | `glycin` | `patched_loader_new` |
| `MemoryFormatSelection` is a `bit_set[MemoryFormatSelectionBit; u32]`, members without the `MEMORY_SELECTION_` prefix (DECISIONS §2) | `glycin` | `#assert`s on the size and bit indices in `patched.odin` |
| none | `glycin_gtk4` | `patched_frame_get_texture` pins the generated signature |

`scripts/check-generated.sh` (`make check-generated`, run by `make lint`) fails if either of the
two `[^]T` parameters above comes back, or if a `va_list` procedure is bound. The audit read
every pointer parameter whose name ends in `s`: those two are the only ones, and both are
already corrected. The headers have no `va_list` procedure; the fork of runic would skip one.
