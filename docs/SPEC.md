# Spec — odin-glycin

## Packages

```
glycin/        package glycin: generated by runic from glycin/rune.yml
glycin_gtk4/   package glycin_gtk4: generated by runic from glycin_gtk4/rune.yml
```

Import through the `glycin` collection: `import "glycin:<package>"`.

| package | library | imports |
|---|---|---|
| `glycin` | libglycin-2 | `glib:glib`, `glib:gobject`, `glib:gio` |
| `glycin_gtk4` | libglycin-gtk4-2 | `glycin:glycin`, `gtk4:gtk4`, and the `glib:` packages through them |

## Surface

Every public declaration of the bound headers (glycin 2 and libglycin-gtk4 2.2.1), named as runic
names them, plus the hand fixes in [PATCHED.md](PATCHED.md). Names lose the `Gly`, `gly_` and
`GLY_` prefixes (`glycin.loader_new`, `glycin.Frame`), and `gly_gtk_` in `glycin_gtk4`
(`glycin_gtk4.frame_get_texture`).

- Objects are opaque structs used by pointer: `Loader`, `Image`, `Frame`, `FrameRequest`,
  `FrameDetails`, `PixelDensity`, `Creator`, `NewFrame`, `EncodedImage`. Each `*Class` struct holds
  the `gobj.ObjectClass` parent. Release with `gobj.object_unref`.
- `Cicp` is a plain struct, freed with `cicp_free`.
- Enums: `SandboxSelector`, `MemoryFormat`, `ColorMode`, `PhysicalDimensionUnit`, `LoaderError`.
  `MemoryFormat` keeps its group word (`MEMORY_R8G8B8`), as `gtk4.MemoryFormat` does.
- `MemoryFormatSelection` is a `bit_set` over `MemoryFormatSelectionBit` (`{.R8G8B8, .G8}`), for
  `loader_set_accepted_memory_formats`.
- `TYPE_FOO` constants are the `foo_get_type` procedures; `LOADER_ERROR` is `loader_error_quark`.
- Strings are `cstring`. Returned `gchar *` and `GStrv` values are owned by the caller
  (`glib.free`, `glib.strfreev`); `image_get_mime_type` is not.
- Error returns are `^^glib.Error`, nil on success; an error returned is freed with
  `glib.error_free`.
- Async calls take a `^gio.Cancellable`, a `gio.AsyncReadyCallback` and a data pointer, and have a
  `_finish` partner.

## Linking

`foreign import` names `system:glycin-2` and `system:glycin-gtk4-2`. The libraries are not on the
system library path: the program supplies `-L` and a RUNPATH (README, Use).

## Version

The binding records the library version it was generated from. `make test` compares it with the
Version of the staged `.pc` files; the headers have no version macro.
